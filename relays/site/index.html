DaNTe relays

An opt-in directory of public relays, checked on a schedule from a real external vantage point — not a ping, an actual protocol round trip. A relay is only ever listed because its operator added it; from there this also follows the federation graph outward, so one listed relay can surface its whole cluster — every entry found that way is independently verified the same way, never just repeated from what a relay claims about its peers. See relays/README.md to list yours, or the project itself.
